# Главная страница
## Мобильная версия
При свапе кошельков должен быть эффект свапа не внутри самого контейнера с названием а как бы всей страницы то есть это должны быть скажем если 3 кошелька, то создается сперва 2 страницы, одна основа, а вторая спрятана сбоку.
При свапе оно как карусель плавно переходит и подгружает ближайщий кошелек
То есть одновременно оно может держать загруженными 3 кошелька - 2 боковых и центральный
В будущем по такому же принципу и стилю сделаем переключение между вкладками
